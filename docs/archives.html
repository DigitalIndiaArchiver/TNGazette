Originals & archives

Three layers of access, in decreasing order of authority: the official site, this archive's structured index, and Wayback Machine copies of everything.

1. The official source

WhatWhere

Geo-fence: the official site frequently refuses non-Indian IPs, including GitHub's CI runners. Readers outside India: use a VPN with an Indian exit, or pull everything from this archive or the Wayback Machine instead. This is also why the weekly pipeline runs a reachability preflight and skips rather than writing empty data.

2. This archive (structured index)

The datasets give you the listings as data: every part with its date, issue number, description and links. Raw files:

  • data/ folder — browse on GitHub
  • weekly "scrape" commits — the full change history, forever diffable
  • Extracted text of the gazettes themselves, taken from archived PDFs: … markdown documents under data/markdown/ — weekly parts 2008–2023 and extraordinary notifications 2008–2026

3. Wayback Machine (document copies)

Every PDF discovered by the pipeline is submitted to the Internet Archive, and each dataset row records the snapshot:

  • Archived URL — the web.archive.org copy of that PDF
  • Archived Date — when the snapshot was taken
  • Deleted — set to true once the original link stops working

To find any snapshot yourself, paste the original URL into the Wayback Machine. Prefer the original when it works; use the snapshot when it doesn't — that's exactly what it's for.

Citing: for legal work, cite the gazette itself (issue, date, part, page) and keep a copy of the PDF you relied on — official sites redesign and reorganise, and this archive exists so the evidence trail survives anyway.

A note on site history

The publishing site was redesigned in 2026 (the old gazette_list.php-style endpoints died with it), which broke most earlier scrapers and URL patterns. Rows scraped before the redesign keep their legacy link formats in the datasets; newer rows use the base64-parameter URLs. The Deleted column tracks which old links have since gone dead — and the Wayback column is usually where you can still read them.
