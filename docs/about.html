About

Why this exists

The Tamil Nadu Government Gazette is where the state speaks formally: ordinances, land acquisition references, appointments, society registrations, name changes, departmental notifications. It is the journal of record for a state of over 70 million people.

And yet, as a data source it is fragile. The official site exposes only the most recent handful of weekly issues; its URLs have broken across redesigns; links to individual PDFs go dead; and the site sometimes refuses visitors outside India entirely. Anyone doing legal, journalistic or historical research is left chasing documents that were public last month and gone this month.

This project fixes that the boring, durable way: scrape weekly, publish as plain CSV in git, and copy every PDF to the Wayback Machine. No dashboard, no accounts, no way for the archive itself to disappear behind someone's paywall — it's an MIT-licensed repository you can mirror.

How the pipeline works

Once a week, GitHub Actions runs the workflow:

  1. Preflight — check the official site is reachable. If not (geo-fence), skip scraping loudly rather than writing empty data.
  2. Scrape — scrape_ordinary.py walks the latest weekly issues and merges new parts into the year files; scrape_gazettes.py covers extraordinary notifications for the current year.
  3. Guard — unit tests verify schemas, dates and duplicate URLs so a site redesign fails the build instead of silently corrupting the datasets.
  4. Preserve — archive_new_links.py submits every never-archived PDF to the Wayback Machine and records the snapshot.
  5. Extract — scripts/extract_pdfs.py turns reached PDFs into markdown text files under data/markdown/, so the corpus is searchable without the PDFs.
  6. Publish — commit the updated CSVs and regenerate this site's stats.json.

What this is not

  • Not an official source. For anything with legal weight, read the gazette itself and keep your own copy.
  • Not complete. Ordinary gazettes run 2008–2023, then skip 2024 and 2025, then resume with every weekly issue of 2026 to date. Those two missing years are a redesign casualty: the old listing endpoints died before the new ones were scraped, and the redesigned listing only ever shows the latest ~38 issues. Recovering 2024–2025 means excavating Wayback captures of the old listing pages — an open issue.
  • Not human-verified. Index descriptions are transcribed as published, and the markdown transcripts in data/markdown/ are machine-extracted — accurate enough to search, not to quote without checking the PDF.

Contributing

Bugs, schema opinions, coverage requests: open an issue on GitHub. Code contributions follow the repo's AGENTS.md: tests for schema contracts, no network in unit tests, loud failures over silent gaps.
