The data

Plain CSV and Parquet, one row per gazette part or notification, updated weekly. Everything lives in the data/ folder of the repo — no API, no registration.

File shape

Paths mirror the gazette's own calendar: data/markdown/<kind>/<year>/<issue>-part-<section>.md (for example data/markdown/extraordinary/2017/344-part-iii-section-1a.md). Each file opens with YAML frontmatter tying it back to the dataset:

--- source: "wayback" type: "ordinary" year: "2009" pdf_url: "https://web.archive.org/web/2022…/gazette/2009/43-VI-4.pdf" Part: "9. Part VI—Section 4" Content: "Advertisements by private individuals…" Date: "2009-11-04" Issue: "43" --- CHANGE OF NAMES No. 43] CHENNAI, WEDNESDAY, NOVEMBER 4, 2009 …

Text extraction is automated, so treat transcripts as a finding aid: check the PDF before quoting anything.
