Query it in one line

CSV=https://raw.githubusercontent.com/DigitalIndiaArchiver/TNGazette/main/data/Gazattes_2026.csv duckdb -c "SELECT Date, Issue, count(*) FROM read_csv_auto('$CSV') GROUP BY 1,2 ORDER BY 1 DESC LIMIT 5"

No API, no key, no database to set up — plain CSV on raw.githubusercontent.com, mirrored in the git history forever.
